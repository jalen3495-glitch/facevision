Build a Face Detection Web App with MediaPipe: A Beginner Tutorial

In this tutorial you'll build a small web page that detects faces in a photo and in your webcam feed, entirely in the browser. It follows the same approach FaceVision uses: MediaPipe Tasks Vision loaded as a JavaScript module, the BlazeFace short-range model, and a canvas overlay for the results. You only need a text editor, a modern browser and basic HTML and JavaScript knowledge.

Step 1: Set up the files

Create a folder with two files, index.html and app.js. Because the code uses ES modules and the camera, you must serve it over HTTP rather than opening the file directly. From the folder, run a simple local server such as:

python3 -m http.server 8000

Then open http://localhost:8000. Browsers treat localhost as a secure context, so camera access works. When you publish the site, use HTTPS (GitHub Pages provides it).

Step 2: The HTML

<input id="file" type="file" accept="image/*">
<button id="cam">Use camera</button>
<div id="stage" style="position:relative;display:inline-block">
  <img id="img" style="max-width:100%">
  <video id="video" autoplay playsinline muted style="max-width:100%"></video>
  <canvas id="overlay" style="position:absolute;inset:0;pointer-events:none"></canvas>
</div>
<script type="module" src="app.js"></script>

The canvas sits on top of the image or video and is where we'll draw boxes. pointer-events:none lets clicks pass through to elements below.

Step 3: Load MediaPipe and create a detector

import { FaceDetector, FilesetResolver } from
  "https://cdn.jsdelivr.net/npm/@mediapipe/tasks-vision@1.0.1";

const WASM = "https://cdn.jsdelivr.net/npm/@mediapipe/tasks-vision@1.0.1/wasm";
const MODEL = "https://storage.googleapis.com/mediapipe-models/face_detector/" +
  "blaze_face_short_range/float16/1/blaze_face_short_range.tflite";

async function createDetector(delegate) {
  const vision = await FilesetResolver.forVisionTasks(WASM);
  return FaceDetector.createFromOptions(vision, {
    baseOptions: { modelAssetPath: MODEL, delegate },
    runningMode: "IMAGE",
    minDetectionConfidence: 0.5
  });
}

let detector;
try { detector = await createDetector("GPU"); }
catch { detector = await createDetector("CPU"); }

Key points: pin the library version (here 1.0.1, the version FaceVision uses) so an update can't break your app unexpectedly, and keep the Wasm URL on the same version. Try the GPU delegate first and fall back to CPU if it fails, since not every device supports GPU inference.

Step 4: Draw the results

The detector returns coordinates in the media's intrinsic pixel size, but the element may be displayed at a different size. We convert between the two:

const overlay = document.getElementById("overlay");
const ctx = overlay.getContext("2d");

function draw(result, el, w, h) {
  const r = el.getBoundingClientRect();
  overlay.width = r.width; overlay.height = r.height;
  const sx = r.width / w, sy = r.height / h;
  ctx.clearRect(0, 0, overlay.width, overlay.height);
  ctx.strokeStyle = "#6ea8fe"; ctx.lineWidth = 3;
  for (const d of result.detections) {
    const b = d.boundingBox;
    ctx.strokeRect(b.originX * sx, b.originY * sy, b.width * sx, b.height * sy);
    for (const k of d.keypoints) {   // keypoints are normalised 0..1
      ctx.fillRect(k.x * r.width - 2, k.y * r.height - 2, 4, 4);
    }
  }
}

Note that bounding boxes are in pixels while keypoints are normalised to the range 0 to 1, so they're scaled differently. Mixing these up is the most common bug in beginner projects.

Step 5: Detect faces in an image

const img = document.getElementById("img");
let objectUrl;
document.getElementById("file").addEventListener("change", e => {
  const f = e.target.files[0]; if (!f) return;
  if (objectUrl) URL.revokeObjectURL(objectUrl);
  objectUrl = URL.createObjectURL(f);
  img.onload = async () => {
    await detector.setOptions({ runningMode: "IMAGE" });
    const result = detector.detect(img);
    draw(result, img, img.naturalWidth, img.naturalHeight);
  };
  img.src = objectUrl;
});

URL.createObjectURL lets the browser display the chosen file without uploading it anywhere. Revoking the old URL frees memory when the user picks another image.

Step 6: Detect faces in webcam video

const video = document.getElementById("video");
document.getElementById("cam").addEventListener("click", async () => {
  const stream = await navigator.mediaDevices.getUserMedia({ video: true });
  video.srcObject = stream;
  await detector.setOptions({ runningMode: "VIDEO" });
  const loop = () => {
    if (video.readyState >= 2) {
      const result = detector.detectForVideo(video, performance.now());
      draw(result, video, video.videoWidth, video.videoHeight);
    }
    requestAnimationFrame(loop);
  };
  loop();
});

getUserMedia prompts the user for permission (see MDN's reference). In VIDEO mode you must pass an increasing timestamp with each frame; performance.now() works well. In a real app, also stop the camera tracks with stream.getTracks().forEach(t => t.stop()) when the user is done, so the camera light turns off.

Step 7: Make it robust

  • Show status. Loading the model takes a moment; display "Loading…" and disable buttons until ready.
  • Handle errors. Wrap camera access in try/catch; users may deny permission or have no camera.
  • Clean up. Stop camera tracks and revoke object URLs.
  • Redraw on resize. The displayed size changes with the window, so recompute the overlay.

Step 8: Publish to GitHub Pages

Push your folder to a GitHub repository, then enable Pages in the repository settings and choose your branch. Adding an empty .nojekyll file tells Pages to serve files exactly as they are. Your app gets an HTTPS address, so camera access works for visitors.

Keep it private

Everything above runs in the visitor's browser: images and video frames never leave the device. If you add analytics, make it opt-in and send only coarse events, as FaceVision does. Respect the line between detection and recognition; see our explainer.
