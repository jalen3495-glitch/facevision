What Happens to Your Photo After You Close the Tab

Published November 23, 2026

If you pick a photo for face detection, it is reasonable to ask where that file goes. This article follows a picture through FaceVision, from the moment you choose it to the moment you close the tab.

The short answer

FaceVision reads the photo in your browser so it can draw boxes on a preview. It does not upload the file to our servers, and it does not write the picture into a database. When you close the tab, that preview is discarded with the page.

That is the design. The rest of this article explains the few exceptions that are easy to misunderstand.

What "choosing a photo" actually does

When you tap "Choose image" or drop a file onto the preview, the browser does not send the file to a folder on our host. JavaScript creates a temporary local address, called an object URL, that points at the file already on your device. The image tag on the page reads from that address. The detector then looks at the pixels in that image element.

You should see the same picture you selected, with boxes overlaid. Those boxes are drawn on a canvas in the page. They are not baked into a new file unless you take a screenshot yourself.

What is not stored

FaceVision does not keep:

  • the photo file;
  • face coordinates or landmarks;
  • a face template or embedding that could be used later to recognise someone;
  • your name, or any caption you did not type (you are not asked to type one).

If you leave optional analytics switched off, which is the default, we also do not record that you analysed a picture. If you switch analytics on, and if an analytics server has been configured, the site may send a coarse event such as "a photo was analysed and the detector found 1 face". That event does not include the image.

What can still linger on your own device

Your device and browser may still hold traces that we do not control:

  • The original file stays in your photos or downloads, exactly where it was. We never needed a copy of that folder.
  • Memory and cache. While the tab is open, the decoded image sits in the page's memory. Browsers can also cache the FaceVision page itself, and the detection model, so the tool loads faster next time. Caching the model is not the same as caching your photo.
  • Screenshots and screen recordings that you, or another app, take of the preview are ordinary pictures on your device or in that other app.
  • localStorage may remember only your analytics preference, not the photo.

Closing the tab, and opening another one

On close, FaceVision revokes the temporary object URL and stops any camera tracks. A new visit starts with an empty preview. We cannot "reload your last photo" because we never stored it.

If you want to analyse the same picture again, you choose the file once more from your device.

A note about the model download

The first time you load the detector, your browser downloads a library and a model from public CDNs. Those providers can see a normal web request (for example an IP address and user agent), the same way they would for any other file on a website. They do not receive the photo you selected.
